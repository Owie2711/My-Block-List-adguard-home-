# My Block List for AdGuard Home

A curated and merged DNS blocklist for AdGuard Home.

Instead of adding dozens of individual blocklists, this project combines multiple trusted sources into a single optimized list that is easy to maintain and simple to use.

## Features

- 🚫 Blocks advertisements
- 👀 Blocks trackers
- 🦠 Blocks malware domains
- 🎣 Blocks phishing domains
- 📡 Blocks telemetry and spyware
- 🔄 Automatically merged and updated
- ⚡ One URL instead of managing multiple lists
- 🏠 Designed for AdGuard Home

---

## Installation

### AdGuard Home

1. Open your AdGuard Home dashboard.
2. Navigate to:

```
Filters → DNS Blocklists
```

3. Click:

```
Add Blocklist
```

4. Use the following URL:

```
https://raw.githubusercontent.com/Owie2711/My-Block-List-adguard-home/main/merged.txt
```

5. Save and update the filters.

## What's Included?

This repository merges various publicly available and trusted DNS blocklists.

Typical categories include:

- Ads
- Analytics
- Trackers
- Malware
- Phishing
- Spyware
- Telemetry
- Mobile advertising
- Smart TV tracking
- Cryptocurrency miners
- Scam domains

The exact sources may change over time as lists are updated or replaced.

Managing many blocklists can become tedious.

Instead of adding:

- AdGuard DNS
- AdAway
- Steven Black
- OISD

- WindowsSpyBlocker
- and many others...

...you only need a single URL.

Benefits:

- Easier maintenance
- Faster setup
- Centralized updates
- Cleaner AdGuard Home configuration

## Updates

This list is periodically regenerated to include the latest entries from the upstream blocklists.

No manual configuration is required after adding the URL to AdGuard Home.

## False Positives

DNS blocklists may occasionally block legitimate domains.

If you encounter a false positive:

- Open an Issue.
- Include the blocked domain.
- Provide a brief explanation.
