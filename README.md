# My Block List for AdGuard Home

A curated and automatically merged DNS blocklist for AdGuard Home.

This project combines multiple trusted blocklist sources into a single, easy-to-use filter, helping you block ads, trackers, malware, phishing, telemetry, and other unwanted domains without managing dozens of separate lists.

## Features

- 🚫 Blocks advertisements
- 👀 Blocks tracking and analytics
- 🦠 Blocks malware domains
- 🎣 Blocks phishing and scam websites
- 📡 Blocks telemetry and spyware
- ⚡ Single URL for easy setup
- 🔄 Regularly updated merged list
- 🏠 Optimized for AdGuard Home
- 🔧 Compatible with other DNS filtering solutions

---

# Quick Start

Simply add the following URL to your DNS filtering software:

```
https://raw.githubusercontent.com/Owie2711/My-Block-List-adguard-home-/main/merged.txt
```

---

# Installation

## AdGuard Home

1. Open AdGuard Home.
2. Navigate to:

```
Filters → DNS Blocklists
```

3. Click **Add blocklist**.
4. Paste:

```
https://raw.githubusercontent.com/Owie2711/My-Block-List-adguard-home-/main/merged.txt
```

5. Save your changes.
6. Update the filters.

That's it!

# Why Use This List?

Managing many separate blocklists can be inconvenient.

Instead of adding multiple sources individually, this project provides:

- One URL
- Easier maintenance
- Simplified configuration
- Regular updates
- Centralized management

Simply add one blocklist and let this repository handle the rest.

# Updates

The merged blocklist is periodically updated to keep up with upstream changes and newly discovered domains.

No additional configuration is required after adding the list to your DNS server.

# False Positives

While every effort is made to reduce false positives, legitimate domains may occasionally be blocked.

If you find a problem:

- Open an Issue.
- Include the affected domain.
- Provide a short explanation.

Feedback is always appreciated.
